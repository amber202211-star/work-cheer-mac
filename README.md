# 上班鼓励器 · macOS

一个深色桌面悬浮工具，让每一秒努力都看得见。

## 功能

- 按排班自动计薪：默认周一至周五 09:00–18:00，无需开始或暂停。
- 今日收入、下班倒计时、工时进度、本月累计。
- 自选每周上班日期、上下班时间及月度工资。
- 每日更新「今日宜……」。
- 可拖动、置顶，收起后从菜单栏「薪」恢复。
- 数据仅保存在本机，不联网、不上传工资信息。

## 当前状态

这是原生 SwiftUI / AppKit 源码。**尚未在 macOS 上编译及实测，没有已验证的应用安装包。** 构建脚本会在目标 Mac 上编译并运行计薪自检，成功后生成 `.app`。

## 在 Mac 上生成应用

目标系统：macOS 12 或更新版本。支持在 Apple 芯片或 Intel Mac 上生成对应架构的版本。

1. 下载并解压仓库。
2. 打开终端，输入 `bash` 和一个空格，再把 `Build.command` 拖入终端，按回车。
3. 如果提示安装 Apple Command Line Tools，完成苹果的免费安装后重新运行脚本。
4. 编译成功后生成并打开 `上班鼓励器.app`。可将它拖入「应用程序」，以后双击运行。

也可以进入仓库目录后运行：

```bash
bash Build.command
```

无需付费开发者账号。脚本进行本地临时签名，不关闭系统安全检查；产物未作 Apple 公证。已有 `.app` 不会被覆盖。

## 计算方式

月薪除以当月排班工作日数量，再按当日排班时长计算每秒收入。收入从排班开始时间自动累计，至下班时间截止。本月累计包含已过去的排班时间，关闭应用不影响累计。

修改设置会重新计算；不自动扣除午休和节假日。跨午夜班次归属开始日。日期与时区跟随 Mac 系统设置。数值是排班估算，不是工资单。
